## 1. Контекст Проекта (Для Партнеров)

### Проблема (The Gap)
Рынок предсказаний (Polymarket) страдает от **асимметрии информации**.
В стандартном интерфейсе пользователь видит только *общий объем* и *цену*. Он не видит, **КТО** двигает цену.
*   *Пример*: Объем $50,000 может быть создан 5000 мелкими игроками ("Толпа") или одним игроком ("Инсайдер"). Для цены это одинаково, но для прогноза — это фундаментальная разница.

### Решение (The Solution)
**WhaleScope** — это "Рентген" для рынка.
Мы подключаемся к биржевому стакану (CLOB) напрямую и анализируем каждую сделку в миллисекундах.
Наша цель — **Деанонимизация потока денег**. Мы определяем:
1.  **Fresh Wallets ("Burner Accounts")**: Инсайдеры почти всегда используют новые кошельки. Мы ловим их моментально.
2.  **Smart Money Tracking**: Мы ведем базу успешных игроков. Если "Кит" с винрейтом 80% заходит в рынок — мы это подсвечиваем.

### Стратегия Развития (4 Столпа)
1.  **Web Dashboard**: Полноценный аналитический терминал.
2.  **Chrome Extension**: "HUD" для быстрого анализа прямо на сайте.
3.  **Auto-Trading Bot**: Автоматическая торговля по сигналам "Левиафанов".
4.  **Wallet Checker (Free)**: Бесплатный модуль-магнит для привлечения трафика (проверка истории кошелька).

## 3. Компоненты Системы

### 3.1 The Hybrid Ingestor (`apps/api/src/ingestor.ts`)
Движок сбора данных работает в двух потоках:

1.  **Stream A (Pulse)**:
    *   **Протокол**: WebSocket (`wss://ws-subscriptions-clob.polymarket.com/ws/market`).
    *   **Цель**: Показывать "жизнь" в логах и (в будущем) стримить цены на клиент.
    *   *Примечание*: Сейчас используется в основном для диагностики (логирование `⚡ [Pulse]`).

2.  **Stream B (Detective)**:
    *   **Протокол**: HTTP Polling (`https://data-api.polymarket.com/trades`).
    *   **Алгоритм**: "Round Robin". Скрипт проходит по списку отслеживаемых рынков и запрашивает последние сделки.
    *   **Логика**:
        *   Сделка проверяется через `processedTradeIds` (дедупликация).
        *   Если сделка крупная и интересная -> сохраняется в БД как `Signal`.

### 3.2 Strategy Service (`apps/api/src/services/strategy.service.ts`)
Здесь находится "Мозг" системы.

#### Формула: Radar Score (0-100)
Оценка вероятности инсайда. Складывается из трех показателей:

1.  **Freshness (Свежесть)**: **Макс 40 баллов**
    *   Если кошелек "свежий" (Winrate = 0% и PnL = 0), он получает +40.
    *   *Логика*: Инсайдеры часто используют новые "Burner Wallets".

2.  **Conviction (Уверенность)**: **Макс 40 баллов**
    *   >$500: +10
    *   >$1,000: +20
    *   >$2,000: +30
    *   >$5,000: +40 (Максимум)

3.  **Timing (Тайминг)**: **Макс 20 баллов**
    *   Если объем рынка < $500k: +10
    *   Если объем рынка < $100k: +20
    *   *Логика*: Вход в рынок до того, как он стал популярным.

**Итоговые Вердикты**:
*   **> 80**: `INSIDER` (High Confidence)
*   **> 60**: `INSIDER` (Possible)
*   **Остальное**: Игнор или обычный трейд.

### 3.3 Database Schema (`packages/db/prisma/schema.prisma`)
Ключевые таблицы:

*   **Whale**: Профиль игрока.
    *   `tags`: Строка, например "Smart,Insider".
    *   `score`: Глобальный рейтинг кита.

*   **Signal**: Конкретная сделка (сигнал).
    *   `status`: OPEN / WON / LOST.
    *   `outcome`: "Yes" / "No" / "UNK" (если метаданные не подгрузились).
    *   `marketSlug`: Технический ID рынка.

## 4. Клиентские Приложения

### 4.1 Chrome Extension (`apps/extension`)
*   **Тип**: Content Script (`src/contents/overlay.tsx`).
*   **Инъекция**: Встраивается в DOM на страницах `polymarket.com/event/*`.
*   **API**: Опрашивает `http://87.120.186.161:3001/api/markets/:slug/sentiment`.
*   **Фича**: Отображает бар настроений (Быки/Медведи/Нейтрально).

### 4.2 Web Dashboard (`apps/web`)
*   **Тип**: Next.js App (`app/page.tsx`).
*   **Статус**: Функциональный прототип "Alpha Stream".
*   **API**: Опрашивает `/api/signals/feed` (Требует переключения с localhost на VPS для продакшена).
*   **Фичи**: Таблица сигналов в реальном времени, цветовая кодировка китов (Leviathan = Gold, Shark = Purple).

1.  **Web Dashboard URL**: В коде сайта сейчас зашит `localhost:3001`. Перед деплоем сайта нужно заменить на IP VPS.
